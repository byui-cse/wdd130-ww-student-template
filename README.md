# WDD 130 Starting Template Repository

This repository provides the starter files, practice activities, and folder structure for **WDD 130: Web Fundamentals**. Use it as the foundation for your coursework as you learn HTML, CSS, Git, GitHub, and GitHub Pages.

## Getting started

1. Create your own copy of this repository using GitHub's **Use this template** button, or follow your instructor's directions for obtaining the repository.
2. Clone your copy to your computer and open the folder in Visual Studio Code.
3. When prompted, install the recommended extensions: **Five Server** and **Code Spell Checker**.
4. Open the assignment file specified by your instructor and use Five Server to preview it in a browser.
5. Commit and push your work regularly. Follow the course instructions to publish the required site with GitHub Pages.

## Repository structure

- `index.html`: the starting page for the repository.
- `week01` through `week05`: course activities organized by week.
- `images`: shared image assets.
- `styles`: shared CSS files.
- `.vscode`: recommended extensions and workspace settings for Visual Studio Code.

Work only in the files and folders identified by your assignment instructions. Keep file names, folder names, and relative paths accurate so that links, styles, images, and GitHub Pages work correctly.

## Practice and solution files

Some activities include files whose names end in `-solution`. These are reference materials for learning and comparison. Follow your instructor's directions about when to view or use them, and complete your assigned work in the appropriate non-solution file.

## Using AI in WDD 130

AI can be useful as a tutor, but it must not complete your coursework.

- Do use AI to explain HTML, CSS, Git, GitHub, or VS Code errors; to ask conceptual questions; or to create separate practice problems.
- Do not use AI to generate HTML or CSS that you submit as your own work, or to answer quiz questions directly.
- If you use AI, ask for guiding questions and explanations. Write the code yourself. When examples are needed, ask for a different but similar problem rather than your assignment's solution.
- After submitting an assignment, you may use AI to review your finished work and suggest improvements.

Questions about the course policy should be directed to your instructor on Microsoft Teams. Violations of the AI policy may result in assignment, course, or program consequences.
